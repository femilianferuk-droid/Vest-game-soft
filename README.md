# Vest Game Soft

Telegram-бот для автоматизации работы с аккаунтами Telegram:
рассылки, автолайкинг, парсинг, автоответчик, скрипты и AI-генератор текста.

## Возможности

- 👥 **Менеджер аккаунтов** — добавление Telegram-аккаунтов (Telethon) и прокси.
- 📨 **Рассылка в чаты** — отправка сообщений в выбранные чаты (одновременно или с задержкой).
- 💬 **Рассылка в ЛС** — массовая отправка личных сообщений по списку пользователей.
- ⏰ **Отложенная рассылка** — запуск по расписанию (МСК).
- 🔔 **Автоответчик** — ответы по ключевым словам или через AI.
- 👍 **Автолайкинг** — автоматические реакции на новые сообщения.
- 🚪 **Вступление в чаты** — массовый join по списку ссылок.
- 🧹 **Удаление сообщений** — очистка своих сообщений.
- 👥 **Парсинг чата** — выгрузка участников с фильтрами.
- ▶ **Скрипты** — запуск чужих ботов и нажатие заданной кнопки.
- 🧠 **AI Генератор** — 3 варианта текста под вашу тему.

## Раздел «Помощь»

В главном меню → «Помощь» теперь есть **отдельные кнопки по каждой фиче**.
Нажав на любую из них, вы получите подробную пошаговую инструкцию:
что делает функция, как её запустить, советы по безопасному использованию.

Доступные кнопки:
- 👥 Менеджер аккаунтов
- 📨 Рассылка
- 💬 Рассылка в ЛС
- ⏰ Отложенная рассылка
- 🔔 Автоответчик
- 👍 Автолайкинг
- 🚪 Вступление в чаты
- 🧹 Удаление сообщений
- 👥 Парсинг чата
- ▶ Скрипты
- 🧠 AI Генератор

Под кнопками фич — ссылки на «Политику конфиденциальности» и
«Пользовательское соглашение», кнопка «Назад» в главное меню.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
export BOT_TOKEN="..."
export API_ID="..."
export API_HASH="..."
export DATABASE_URL="postgres://..."
python bot.py
```

Переменные окружения:
- `BOT_TOKEN` — токен бота от @BotFather.
- `API_ID` / `API_HASH` — данные приложения на https://my.telegram.org.
- `DATABASE_URL` — строка подключения к PostgreSQL.
- `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` — опционально, для AI-генератора.
